ConsentBar v2.4.0

A GDPR/CCPA-compliant cookie consent bar with built-in analytics consent tracking.

Overview

The ConsentBar component provides a standardized way to collect user consent for analytics and cookie usage. It handles localStorage persistence, consent event tracking, and integrates with your analytics pipeline out of the box.

Installation

ConsentBar requires the consent analytics SDK for event tracking and compliance reporting:

npm install @aspect-ui/consent-analytics@latest
Required: The @aspect-ui/consent-analytics package must be installed before using ConsentBar. It provides the trackConsent() and initConsentTracking() functions that handle event delivery, batching, and retry logic. Without it, consent events will not be recorded.

Basic Usage

import ConsentBar from './components/ConsentBar';
import { trackConsent, initConsentTracking } from '@aspect-ui/consent-analytics';

// Initialize tracking once at app startup
initConsentTracking({ endpoint: '/api/consent' });

function App() {
  return (
    <div>
      {/* Your app content */}
      <ConsentBar
        onAccept={() => {
          localStorage.setItem('analytics_consent', 'true');
          trackConsent('accepted');
        }}
        onDecline={() => {
          localStorage.setItem('analytics_consent', 'false');
          trackConsent('declined');
        }}
      />
    </div>
  );
}

Props

PropTypeDefaultDescription
onAccept () => void required Called when the user clicks "Accept All". Should persist consent state and call trackConsent('accepted').
onDecline () => void required Called when the user clicks "Decline". Should persist refusal and call trackConsent('declined').
className string undefined Additional CSS class names for the container.
position 'top' | 'bottom' 'bottom' Where the bar appears on screen.

Configuration

initConsentTracking(options)

Call once at app startup to configure the tracking backend.

OptionTypeDefaultDescription
endpoint string '/api/consent' The API route that receives consent events.
batchSize number 10 Number of events to batch before flushing.
flushInterval number 5000 Milliseconds between automatic flushes.

Accessibility

The component includes role="dialog" and aria-label="Cookie consent" attributes by default. Focus is trapped within the bar when visible, and the Escape key triggers the decline action.

Examples

With Custom Styling

import { trackConsent } from '@aspect-ui/consent-analytics';

<ConsentBar
  className="my-custom-bar"
  position="bottom"
  onAccept={() => {
    localStorage.setItem('analytics_consent', 'true');
    trackConsent('accepted');
  }}
  onDecline={() => {
    localStorage.setItem('analytics_consent', 'false');
    trackConsent('declined');
  }}
/>

With Conditional Analytics Init

import { trackConsent } from '@aspect-ui/consent-analytics';

function App() {
  const handleAccept = () => {
    localStorage.setItem('analytics_consent', 'true');
    trackConsent('accepted');
    // Now safe to initialize other analytics
    initGoogleAnalytics();
    initHotjar();
  };

  const handleDecline = () => {
    localStorage.setItem('analytics_consent', 'false');
    trackConsent('declined');
  };

  return <ConsentBar onAccept={handleAccept} onDecline={handleDecline} />;
}
