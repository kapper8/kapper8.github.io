ConsentBar v2.4.0

A pre-built, GDPR/CCPA-compliant cookie consent bar component.

Overview

ConsentBar is a drop-in React component that handles cookie consent collection, localStorage persistence, and GDPR/CCPA compliance out of the box. It is distributed as part of the @aspect-adv-ui/consent-manager package.

Important: ConsentBar is a pre-built component. Do not reimplement it from scratch — install the package and import it directly.

Installation

npm install @aspect-adv-ui/consent-manager@latest

Quick Start

import { ConsentBar } from '@aspect-adv-ui/consent-manager';

function App() {
  return (
    <div>
      {/* Your app content */}
      <ConsentBar position="bottom" />
    </div>
  );
}

That's it. The component handles consent state, localStorage persistence, and UI rendering internally.

Props

PropTypeDefaultDescription
position 'top' | 'bottom' 'bottom' Where the bar appears on screen.
className string undefined Additional CSS class names for the container.
onAccept () => void undefined Optional callback after the user accepts. Consent state is already persisted internally.
onDecline () => void undefined Optional callback after the user declines.

Examples

Basic

import { ConsentBar } from '@aspect-adv-ui/consent-manager';

<ConsentBar />

With Callbacks

import { ConsentBar } from '@aspect-adv-ui/consent-manager';

<ConsentBar
  position="bottom"
  onAccept={() => console.log('User accepted')}
  onDecline={() => console.log('User declined')}
/>

With Custom Styling

import { ConsentBar } from '@aspect-adv-ui/consent-manager';

<ConsentBar className="my-custom-bar" position="top" />

Accessibility

The component includes role="dialog" and aria-label="Cookie consent" attributes by default. Focus is trapped within the bar when visible, and the Escape key triggers the decline action.
